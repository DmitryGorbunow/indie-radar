# Indie Radar

Personal, non-commercial research tool for discovering potential
software and iOS app opportunities from public Reddit discussions.

The application will use the Reddit API in read-only mode to retrieve
public posts from a limited list of predefined subreddits.

It will not:
- post, comment, vote, or message users;
- collect or infer sensitive personal information;
- sell or redistribute Reddit data;
- use Reddit data to train AI/ML models.

Retrieved content will be analyzed to identify recurring problems,
product opportunities, demand signals, and potential gaps in existing
solutions. The results will be used privately by the developer.
